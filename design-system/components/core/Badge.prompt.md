The mono eyebrow label / tag — UPPERCASE, tracked JetBrains Mono in gold or crimson. Use for section eyebrows, column headers, and meta lines.

```jsx
<Badge>Long-Form Essay</Badge>
<Badge variant="outline" tone="crimson">Temple &amp; Ritual</Badge>
<Badge variant="underline">Freemasonry</Badge>
<Badge onDark>Further Viewing</Badge>
```

Variants: `label` (bare text, default), `outline` (bordered chip), `underline` (2px rule beneath — used as column-header labels). Tones: `gold` (default), `crimson`, `muted`. Set `onDark` on maroon/ink surfaces.
