Scripture citation card — white surface, crimson left-rule, italic serif verse, mono reference line. Use to quote scripture inline in an article.

```jsx
<ScriptureBox reference="1 Timothy 2:5–6">
  "For there is one God, and there is one mediator between God and men, the man Christ Jesus…"
</ScriptureBox>
```

Verse as children, citation via `reference`. Distinguished from PullQuote by the crimson rule + upright serif body.
